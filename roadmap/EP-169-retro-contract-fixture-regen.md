## Context

The EP-9 contract is clean against mimic-code `8bcbd190` (41 tables, no drift) but three ripple effects
would otherwise hit P2 six times over: (1) the contract's `sort_keys` are `[subject_id, <time>]` while
EP-20/23/24/25/26/27 each expect tie-break keys and say "fix the contract with a dated note" — six YAML
edits, each re-hashing the contract and forcing a fixture regeneration; owner decision: **adopt the
tie-breaks now** (deterministic Parquet, itemid row-group pruning) and **keep `microbiologyevents`
`large`** (contract as shipped; EP-25 gets a pickup note); (2) `Contract.content_hash()` covers every
comment/note, is pinned by `tests/fixtures/manifest.json` and asserted by `test_ep11/12`, so any wording
edit breaks the suite — add a load-relevant `structural_hash()`; (3) all fixture id spaces share the
90 000 000 floor so wrong-key joins still match — owner decision: **disjoint floors, regenerate now**
(`GENERATOR_VERSION` 0.1.0 → 0.2.0). Also: no CSV-dialect constant (duplicated in `inventory.py`,
`fixtures/write.py`, and about to be hard-coded a third time by EP-17); nine upstream `TIMESTAMP(3)`
columns leave no trace; the concept coverage of the fixture (which vendored concepts are empty/partial
on it) is undocumented; the fixture-change protocol is unwritten (EP-166 writes the prose in
`tests/README.md`; this brief makes the code match it).

2. **`Contract.structural_hash()`** (SCH-2, FC-4, FXT-2) — sha256 over sorted JSON of load-relevant
   facts only: `(schema, table, csv_path, ordered (name, type, nullable), primary_key, uniqueness_hint,
   sort_keys, time_column, partitioned, load_class, subject_keyed, FK tuples, column-map mechanics)`;
   `fixtures/write.py` records **both** `contract_hash` (full, informational) and `contract_schema_hash`
   (structural) in `manifest.json`, and `test_ep11/12` assert equality on the structural one only;
   `inventory.py` keeps recording the full `content_hash()` (time-of-run provenance) — do **not** switch
   it; `mwh schema list/show` print both; `tests/fixtures/README.md` (generator-rendered) gains one
   sentence naming which fields are hash-relevant so a comment edit no longer triggers a regen.
3. **CSV dialect constant** (SCH-1) — `src/mimicwarehouse/schema/csv_dialect.py`: `DELIM=','`,
   `QUOTE='"'`, `ESCAPE='"'`, `HEADER=True`, `NULLSTR=''`, `ALLOW_QUOTED_NULLS=True` (owner policy,
   D-17: matches upstream `build_mimic.sh` and keeps the two nullability relaxations), `DATEFORMAT` /
   `TIMESTAMPFORMAT` = **None** (rely on DuckDB's ISO cast, which accepts optional fractional seconds —
   verified: `try_strptime(... '%Y-%m-%d %H:%M:%S')` fails on `.123`, `try_cast` succeeds) exposed as
   `Table.read_csv_options() -> dict` (+ `read_csv_columns()` unchanged) and `read_csv_sql(path, table)`;

   `fixtures/catalog.READ_CSV_SQL` import from it (fixture writer keeps emitting `%Y-%m-%d %H:%M:%S`;
